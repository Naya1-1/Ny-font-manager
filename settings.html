字体配置备份
自定义字体储存在浏览器中，若想要分享给他人或更换浏览器使用，请先在此处导出字体配置，后将导出的配置文件导入新浏览器。
当功能开关处于“折叠”状态时，对应功能为关闭状态。

1. 点击 “点击启用字体覆盖”，启用全局/正文/对话/自定义包裹/多语言字体等字体功能。
2. 点击 “点击开启外部聊天字体导入”，启用聊天记录和正则脚本中的网络字体加载。
3. 在 “显示设置” 中可单独开启流式动画、文字动画和阅读样式。

开启后的主开关会显示为流光动画状态。
全局字体：
影响 SillyTavern 整体界面字体，优先级低于聊天正文、对话和自定义包裹字体。

正文字体：
设置聊天消息的全局默认字体。留空则使用主题默认字体。

对话字体：
设置引号内对话内容的专用字体。支持中文引号（“ ”）、英文引号（" "）等；文字动画开启时，也会复用这套对话识别范围。

优先级：
自定义包裹 > 按语言设置 > 对话字体 > 正文字体 > 全局字体。
在此处配置不同语言/脚本（如 CJK 汉字、日文假名、韩文、英文/拉丁文、数字、标点、Emoji 等）使用的特定字体。

特性：
支持在同一句消息里混排多种字体，并可通过规则顺序处理重叠范围的优先级。

优先级：
按语言设置 > 对话字体 > 正文字体。自定义包裹字符会覆盖多语言字体。

提示：
数字/标点若未单独配置，会自动跟随前一段语言的字体（减少视觉断裂）。
为被特定符号包裹的文字设置独立字体。

用法：
设定起始符号（如 『）和结束符号（如 』）。
聊天中被这些符号包裹的内容将应用指定字体；可在阅读样式中继续单独调节这类文本的字号和字距。

优先级：
自定义包裹 > 按语言设置 > 对话字体 > 正文字体。
自动扫描并加载聊天记录与正则脚本中的 CSS 字体链接。

作用：
解决酒馆（SillyTavern）净化样式导致消息内的 @import 字体失效的问题。

支持格式：
CSS @import 语句或 <style> 标签内的引用。
流式输出渲染模式：
“实时显示”会在文本生成过程中显示处理后的内容，是启用流式动画的前提；“结束后处理”会在整段回复完成后统一应用字体与样式。

流式动画效果：
可在“关闭 / 打字机 / 模糊显现 / 流光浮现”之间切换，并调节打字速度。打字机模式可配置光标开关、形状、动画和自定义图片。

文字动画：
为已显示的正文/对话添加低能耗长期动画。可设置全局效果，也可让正文或对话单独覆盖全局；支持效果、颜色、强度和周期调节。

阅读样式：
开启后可按整体、正文、对话分别调节字号、字距、行高、颜色、段距、缩进、字重和倾斜；自定义包裹文本与多语言字体范围也可单独设置字号和字距。

阅读样式预设：
可新建、保存、读取、删除、导出和导入 JSON 预设，方便在不同主题或角色卡之间切换排版。

“实时显示”如遇兼容问题（如字体闪烁、排版错乱），请切回“结束后处理”；长期文字动画主要同步最近的已完成消息。
管理插件使用的额外字体资源。

Web 字体：
粘贴包含 @font-face 或 @import 的 CSS 链接（如 Google Fonts）进行导入。

本地文件：
上传 .woff2、.woff、.ttf、.otf 等字体文件。文件会存储在浏览器本地数据库中，不会上传到服务器。

已导入字体：
可查看、删除已导入字体，或将字体快速设置为全局、正文、对话、自定义包裹字体。

字体配置备份：
可导出/导入已导入字体配置。导出文件会包含本地字体文件数据，适合换浏览器、分享配置或清理浏览器存储前备份。
常见原因：
1. 字体 family 名称与真实字体名不一致，或 Web 字体 CSS 中声明的名称和输入名称不同。
2. Web 字体链接网址失效、无法访问、被跨域策略拦截，或 CSS 内没有有效的 @font-face/@import 字体声明。
3. 本地字体文件损坏、格式不被浏览器支持，或字体文件过大导致首次加载较慢。
4. 本地字体存储在浏览器 IndexedDB 中，更换浏览器、清理站点数据、隐私模式或浏览器禁用存储后，字体文件数据可能丢失。

排查步骤：
1. 先确认字体出现在“已导入字体”列表中，并使用列表里的“设为全局 / 正文 / 对话 / 自定义”按钮应用。
2. 若应用后仍无变化，刷新页面后再试一次；插件会在应用前校验字体是否能被浏览器实际加载。
3. Web 字体请确认 CSS 链接能直接打开，且其中包含有效字体声明；无法稳定访问的 CDN 建议改用本地字体文件。
4. 本地字体优先使用 .woff2 或 .woff；中文大字体建议使用裁剪版本，减少加载延迟。

解决建议：
如果插件提示 family 自动匹配，请优先使用提示中的真实 family 名称。若提示字体文件缺失，请重新导入原字体文件，或从之前导出的“字体配置备份”恢复。清理浏览器存储或迁移浏览器前，建议先导出字体配置备份。
